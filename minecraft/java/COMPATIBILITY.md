# Minecraft: Java Edition in Corsican — versions and checks

Generated by `python3 tools/mcreport.py` from `versions.json`, `keys.tsv`, `co_fr.json`, `history.json`, `inventory.tsv`, `history-report.md` and `other-versions.md`; do not edit by hand. Status by state: [STATUS.md](STATUS.md); contract: [MULTIVERSION.md](MULTIVERSION.md).

**Minecraft: Java Edition in Corsican for 87 versions** (releases 1.6.1 → 26.3). Complete translation of the language files for the listed versions; technical checks with each version's own code.

Availability: in published Corsu releases from 0.23.0.

## One translation for every version

- The 87 releases show 12,532 different (key, English text) pairs with non-empty English (`keys.tsv`).
- The 26.3 translation (`co_fr.json`, 8,557 texts) serves every release wherever the key and its English are exactly 26.3's: 307,736 texts summed over the releases.
- `history.json` holds 3,978 pairs whose English differs from 26.3's: 507 *reused* (26.3's Corsican still says the older English), 1,755 *renamed* (same English under a key renamed since: the Corsican of the new key), 482 *adapted* (26.3's Corsican adapted to the older English), 1,234 *new* (English found nowhere in 26.3: translated).
- A correction to a shared text is made once and reaches every release showing that exact English; a different English is a different pair, so a historical difference stays.

## Limits

- Texts written by AI; second AI pass on a sample of 150 entries of the 3,978 older texts (not on all of them); review by a Corsican speaker: 0.
- Technical check: on 2026-10-19, for each version: Python rules on every text (arguments, `§` codes, language file and pack.mcmeta formats), then that version's own game code (its client jar, SHA-1 checked) loaded the language file and rendered every text: 0 problems (2 or 3 texts per version not rendered because their English itself does not format). Exceptions: text components (chat, advancements) before 26.1: Python rule only; the `pack` section of pack.mcmeta in 1.21.1: not read by the game's code; the code in the `language` section from 1.20: checked in Python; drawing on screen and the resource pack screen are not checked ([details](MULTIVERSION.md), [per version](COMPATIBILITY.md)). This is neither a speaker's review nor a visual check of every screen.
- In the game: only 26.3 has been started with the pack, on the maintainer's Prism Launcher instance (2026-10-16): the game's log shows the pack loaded and messages in Corsican. No per-key visual check has been recorded, which is why [STATUS.md](STATUS.md) counts "seen in game: 0". The other versions have not been started.
- Scope: the game's language files only: not mods, servers or the launcher; splash texts and the End Poem: a separate optional pack. No snapshots, pre-releases or release candidates, no Bedrock, nothing before 1.6.1 (no resource packs). The 832 other entries of Mojang's version manifest are listed in [other-versions.md](other-versions.md) and not claimed.
- Freshness: `tools/mcversions.py verify` records the SHA-256 of the exact `pack.mcmeta` and language file it checked (`versions.json` → `verified`). This page computes them again from today's data: a release whose pack differs shows "check to redo", and `python3 tools/mcreport.py --check` fails until `verify` runs again.
