# Sécurité · Security

[Français](#français) · [English](#english)

## Français

Corsu modifie des logiciels installés (copie de Firefox, fichiers de langue des navigateurs, Discord). Si vous
trouvez une faille, par exemple un moyen pour un site web ou un autre utilisateur de l'ordinateur de piloter l'application
Corsu ou de faire écrire Corsu ailleurs que prévu, ne la publiez pas dans un ticket. Signalez-la en privé avec
[Report a vulnerability](https://github.com/Platykalt/corsu/security/advisories/new) sur GitHub.

Indiquez la version de Corsu, le système et les étapes pour reproduire le problème. Une réponse est donnée dès que
possible, et la correction est publiée dans une nouvelle version avec une note dans le CHANGELOG.

Seule la dernière version publiée reçoit des corrections.

## English

Corsu changes installed software (a copy of Firefox, browser language files, Discord). If you find a vulnerability,
for example a way for a website or another user of the computer to drive the Corsu app or make Corsu write somewhere it
should not, do not post it in an issue. Report it privately with
[Report a vulnerability](https://github.com/Platykalt/corsu/security/advisories/new) on GitHub.

Include the Corsu version, the operating system and the steps to reproduce it. You will get an answer as soon as
possible, and the fix is published in a new release with a note in the CHANGELOG.

Only the latest release receives fixes.
